# 모바일 작업 공간과 계획 도구

- 모바일 상단을 한 줄로 정리하고 중복 정보·영역을 줄였다. 하루 시간표, 44px 주요 조작, 하단 일정 추가/할 일/목록/회고를 유지한다. 360×800에서 기본 시간표 높이450px 이상을 검사한다. 상태 점의 전체 동기화 문구는 접근성 이름/툴팁으로 확인하며, 계정 작업은 설정에서도 접근한다.
- 입력 본문16px, 기본44px 높이, 줄인 패딩·라벨 간격·80px 메모 영역. 모바일 모달은 visualViewport 높이/offset을 반영해 키보드 영역 위에서 본문 스크롤과 저장을 유지한다.
- PC 빈 시간 호버는 실제15분 좌표의1시간 실루엣이며 클릭하면 편집창을 연다. 빈 공간을 드래그하면 선택한 길이를 미리 채운다. 모바일은 빈 공간 한 번 터치로1시간을 선택한다. 기존 시간 블록 이동/리사이즈·겹침 확인·키보드 추가를 유지한다. 더블클릭은 주 진입 방식에서 제거했다.
- 일정 목록에서 제목/메모를 검색하고 이번 주·오늘·전체 범위를 선택한다. 검색 입력 시 전체 범위로 바뀌며 표시 상태가 이를 설명한다. 결과의 ‘이 시간 보기’는 해당 주/하루/시간 범위로 이동한다. `/` 또는 Cmd/Ctrl+K로 검색에 진입하며 열린 대화상자에서는 단축키를 가로채지 않는다.
- ‘빈 시간 추천’은 배치하지 않은 미완료 할 일의 예상 시간(없으면60분)을 사용한다. 길이를 바꿀 수 있다. 실제 가용 시간·휴일·수동 설정·점유 시간·현재 시간·기한을 반영한다. 기한이 지난 할 일은 이를 알리고 지금부터 가능한 시간을 제안한다. 시간이 흐르면 갱신하며 클릭 시 다시 검증한다. 선택 후 연결된 블록 편집창에서 명시적으로 저장한다. 자동 배치/자동 데이터 변경은 없다.

## 기기 달력

모바일에서 새 시간 블록을 저장한 뒤 기기 달력 복사 여부를 묻는다. 확인 시 로컬 ICS 파일을 생성해 기기 공유 기능(지원 시) 또는 파일 저장으로 전달한다. 공유 목록에 달력이 없으면 파일 저장 후 달력에서 열어야 한다. 웹에서 EventKit/기기 달력에 직접 쓰거나 최종 저장을 확인할 수 없으므로 운영체제의 최종 확인이 필요하다. 복사본은 이후 WEEKFLOW 수정/삭제와 동기화되지 않는다. 실제 기기에서의 달력 가져오기 완료는 미검증이다.

일정의 실제 UTC 시작/종료와 안정된 UID를 사용하며 자정·한글·특수문자 escaping 및 UTF-8 75바이트 줄 접기를 검사한다. 파일은 브라우저 안에서 생성하며 개인 일정 내용을 공개 서버에 업로드하지 않는다. ‘다음부터 묻지 않기’는 기기별 localStorage에 보관하며 설정→기본에서 다시 켤 수 있다. 취소·다운로드 실패가 WEEKFLOW의 저장을 취소하지 않는다.

## Push

- 브라우저 권한, 로컬 구독, 서버의 해당 endpoint 등록, 일정 알림 선호를 구분한다. iPhone 브라우저 탭에는 홈 화면 설치 안내를 제공한다.
- 권한 요청은 클릭 제스처에서 첫 await 전에 실행한다. 재등록 실패 시 이미 있던 구독을 파괴하지 않는다. 서버는10개 제한에서도 동일 기기 재등록을 허용한다.
- 테스트는 현재 사용자 소유의 현재 기기 endpoint만 대상으로 보낸다. 과거 클라이언트의 endpoint 없는 요청도 호환한다. 성공 응답은 gateway 접수일 뿐이다.
- SW는 Push를 처리하고 showNotification 요청을 완료한 뒤 개인 내용을 담지 않는 receipt를 앱에 보낸다. 수신 대기는 발송 전 listener를 등록하되 제한 시간은 서버 응답 후 시작한다. OS 배너 표시는 여전히 사용자가 확인해야 한다.
- 기기 표시 테스트와 실제 원격 Push 테스트를 분리했다. Mac/Android OS 알림 허용·집중 모드, iPhone 설치 앱 안내를 제공하며 웹에서 OS 설정을 변경했다고 주장하지 않는다.
- 예약 Cron은5분 주기라 최대 약5분 지연될 수 있다. 미래 일정/마감이 있어야 일정 알림을 만든다. 방해금지 시간에는 보류된다.
