개인정보 처리 안내

적용일: 2026년 11월 16일

WEEKFLOW는 개인용 주간 Todo·타임블로킹 플래너입니다. 이 문서는 앱이 사용하는 정보와 사용자의 관리 방법을 설명합니다.

사용하는 정보와 목적

Google 로그인에서 계정 식별자, 이메일 주소, 이름과 프로필 정보를 받아 Supabase Auth에서 계정 인증과 사용자 구분에 사용합니다. 요청 범위는 기본 로그인 정보인 openid, email, profile입니다. Google 계정 정보를 광고나 판매에 사용하지 않습니다.

사용자가 작성한 Todo·메모·목표·마감·일정·요일 기록·반복 규칙·회고와 개인 설정은 기기 간 동기화와 플래너 기능 제공을 위해 Supabase 데이터베이스에 저장합니다. 사용자 계정별 접근 제어(RLS)를 적용합니다.

기기 저장과 알림

로그인 세션은 브라우저의 Supabase 세션 저장소에 보관됩니다. 오프라인 캐시와 미전송 변경은 계정별 IndexedDB에 임시 저장하고 재접속하면 서버에 전송합니다. 로그아웃 시 해당 기기의 개인 캐시와 대기 큐를 정리합니다. 미동기화 상태에서 브라우저 데이터를 삭제하면 변경을 잃을 수 있습니다.

사용자가 Web Push에 동의하면 기기의 Push endpoint와 구독 키를 Supabase에 저장하고 일정·마감·회고 알림 전달에 사용합니다. 알림함·예약·기기별 전달 결과를 운영 기록으로 저장합니다. 잠금 화면 알림에는 일반적인 안내만 사용합니다. 브라우저 권한과 설정에서 알림을 끄고 기기 구독을 해제할 수 있습니다.

처리 서비스

정적 웹 호스팅에는 GitHub Pages, 인증·데이터 저장·서버 작업에는 Supabase, Google 로그인에는 Google, Push 전달에는 해당 브라우저의 Push 서비스를 사용합니다. 이 제공자들은 각 정책에 따라 인증·접속·보안 로그를 처리할 수 있습니다. 공휴일 API에는 개인 Todo를 전송하지 않습니다.

사용자 데이터에 접근할 수 있는 운영자는 서비스 유지·보안·사용자가 요청한 지원에 필요한 범위에서만 정보를 처리합니다. 서비스 코드는 인증 비밀값과 메모 내용을 운영 로그에 출력하지 않습니다.

보관·내보내기·삭제

계정 데이터는 사용자가 사용하는 동안 보관합니다. 설정에서 전체 도메인 데이터를 JSON으로 내보내거나 Todo를 CSV로 내보낼 수 있습니다. 백업에는 로그인 토큰과 Push 구독 비밀을 포함하지 않습니다. 내보낸 파일의 보관과 공유는 사용자가 관리합니다.

설정 → 계정 → 계정 영구 삭제에서 최근 로그인 확인과 이중 확인 후 계정 및 연결 데이터를 운영 데이터베이스에서 삭제합니다. 공급자 측 보안·백업 기록의 보관은 해당 공급자의 정책에 따릅니다. 삭제나 접근 문제는 아래 운영 연락처로 요청할 수 있습니다.

변경과 연락처

정보 사용 방식이 변경되면 이 문서와 앱 안내를 갱신하고, 새로운 권한이 필요하면 사용자 동의를 받습니다.
